# Метеощоденник · Weather Journal v7

Статичний PWA без збірки й залежностей. Мови: uk, en, pl, de, es, ro, ar.
Авторка: Олеся Бохонок.

## Розгортання (GitHub Pages)
1. Завантажте **весь вміст** папки в корінь репозиторію (або в підпапку) — зберігайте структуру `locales/`, `icons/`.
2. Settings → Pages → Branch: `main` / root.
3. Відкрийте `https://<user>.github.io/<repo>/`.

## Локальна перевірка
Подвійний клік по `index.html` **не працює** (CSP, service worker і підвантаження мов потребують http).
```
python3 -m http.server 8000     # потім http://localhost:8000
```

## Випуск оновлення
Змініть `VERSION` у `sw.js` (наприклад `mj7-2`). Користувачі побачать банер «Доступна нова версія».

## Додати мову
1. Скопіюйте `locales/en.js` → `locales/xx.js`, змініть `.xx =`, `meta` (`name`, `dir`, `weekStart`), переклад.
2. Форми множини — за CLDR для мови (pl: one/few/many/other; ar: zero/one/two/few/many/other).
3. Додайте `{c:'xx', ...}` у масив `LANGS` в `app.js` і файл у `SHELL` у `sw.js`.

## Безпека й приватність
- Суворий CSP: без inline-скриптів і стилів; зовнішні запити лише до Open-Meteo та Nominatim (OpenStreetMap).
- Дані — тільки в `localStorage` цього браузера; на сервер нічого не надсилається. Координати для визначення назви міста округлюються до ~1 км.
- «Дорослий тест» (множення) — лише бар'єр від випадкових натискань, не захист.
- PIN профілю зберігається як хеш і лише ховає журнал в інтерфейсі; це не шифрування.
- Дані Open-Meteo безкоштовні для некомерційного використання; Nominatim має політику ≤1 запит/с — для великого трафіку потрібен власний сервіс.
- Переклади pl, de, es, ro, ar — чорнові; перед публікацією їх варто дати на перегляд носіям мови.
